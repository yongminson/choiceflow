음식 추천에서 지도를 열면 현재 위치가 아닌 곳이 나왔다. 위치 권한을 받아
서버로 좌표까지 보내놓고 정작 지도 링크에는 넘기지 않아, 검색이 IP 기준
임의 지역에서 이뤄지고 있었다.

- buildNearbyMapUrl 을 추가해 좌표가 있으면 /@lat,lng,15z 형식으로 지도
  중심을 사용자 위치에 고정한다. 좌표가 없을 때만 기존 검색 URL을 쓴다.
- AI 메뉴 경로와 정적 폴백 경로 모두에 위치를 전달한다.
- 버튼 문구도 위치 사용 여부에 따라 "내 주변에서 이 메뉴 찾기"로 구분한다.

제휴 링크 진단
- GET /api/coupang/diagnose 를 추가한다. 상품 검색과 딥링크를 각각 시도해
  어느 단계에서 끊기는지, 실제로 어떤 종류의 링크가 나가는지를 한 번에
  보여준다. 리포트에 클릭이 잡히지 않을 때 키·권한·링크 형태 중 무엇이
  문제인지 구분할 방법이 없어 추가했다.
- COUPANG_DIAGNOSTIC_TOKEN 으로 보호하고 키 값은 응답에 포함하지 않는다.

- 2026-07-31 종료된 NAVER 쇼핑검색 연동 코드를 제거한다. 쿠팡 상품 검색으로
  대체돼 더 이상 호출되지 않는다.

+/**
+ * 지도 검색어 정리.
+ * AI가 "1인용 냉동삼겹살 밀키트" 같은 상품형 문구를 만들면 지도에는
+ * 상호가 하나도 뜨지 않는다. 상품 표현을 걷어내고 핵심 메뉴명만 남긴다.
+ */
+export function toMapKeyword(value: string): string {
+  const stripped = value
+    // \b 는 한글 뒤에서 경계로 잡히지 않아 한글 단위와 영문 단위를 나눠 처리한다.
+    .replace(/\d+\s*(인용|인분|개입|봉|팩)/g, " ")
+    .replace(/\d+\s*(kg|g|ml|l)(?![a-z가-힣])/gi, " ")
+    .replace(
+      /(밀키트|간편식|냉동|즉석|가정간편식|HMR|세트|선물세트|포장|배달|택배|정품|무료배송)/g,
+      " "
+    )
+    .replace(/\s+/g, " ")
+    .trim();
+  const base = stripped || value;
+  // 지도 검색은 단어 2개를 넘기면 결과가 급격히 줄어든다.
