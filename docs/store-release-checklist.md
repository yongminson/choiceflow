# ChoiceFlow 스토어 출시 체크리스트

## 공통 차단 항목

- [ ] 개인정보처리방침의 대표자명, 사업자 주소, 전화번호를 실제 정보로 보완
- [ ] 쿠팡 파트너스 링크가 각 플랫폼 정책에서 허용되는지 최신 정책 확인
- [ ] 운영 도메인의 로그인, 위치, 외부 링크, 오류 화면을 실제 기기에서 확인
- [ ] 서버 비밀키가 APK/AAB/AIT 및 클라이언트 코드에 포함되지 않았는지 확인
- [ ] 결제·환불 정책과 실제 화면의 “무료/유료” 문구 불일치 해소

## Google Play

- [ ] Play Console 계정 인증
- [ ] 패키지명 `kr.co.ymstudio.choiceflow` 최종 승인
- [ ] API 36 이상 타깃 확인
- [ ] 최종 런처 아이콘·스플래시 적용
- [ ] Play App Signing용 업로드 키 생성 및 별도 백업
- [ ] Android App Bundle(AAB) 생성
- [ ] 데이터 보안 양식에 계정, 위치, 결제, 상담, 분석·진단 항목 기재
- [ ] 위치 권한 사용 사유와 권한 거부 흐름 확인
- [ ] 디지털 크레딧은 Play Billing 구현 또는 승인된 대체 결제 프로그램 가입 전 노출 금지
- [ ] 내부 테스트 트랙에서 최소 2종 실제 Android 기기 검증

## 앱인토스

- [ ] 워크스페이스와 앱 생성
- [ ] `apps-in-toss.config.ts`의 appName을 콘솔 값과 일치시키고 최종 아이콘 업로드
- [ ] 위치 권한 `geolocation/access` 심사 사유 입력
- [ ] 샌드박스 앱에서 iframe 쿠키와 Supabase 로그인 동작 확인
- [ ] 쿠팡·지도 외부 링크가 공식 `openURL` 요구사항에 맞는지 확인
- [ ] 디지털 결제는 앱인토스 전용 결제 정책과 SDK를 확인하기 전 노출 금지
- [ ] `.ait` 생성 후 콘솔 QR 테스트와 심사 제출
