### 무엇이 잘못돼 있었나 (운영자용)

몇 달 동안 쿠팡 파트너스 리포트에 클릭과 결제가 잡히지 않았다. 코드를 다시 훑어 원인 네 가지를 찾았다.

| # | 원인 | 영향 받은 곳 | 상태 |
|---|------|------------|------|
| 1 | 토스 미니앱 안에서 쿠팡 버튼이 아예 열리지 않음. 미니앱은 웹사이트를 iframe 으로 감싸는데, 토스 WebView 안의 iframe 은 새 창(`target="_blank"`) 링크를 열어 주지 않는다. 토스는 외부 링크를 SDK `openURL` 로 열게 한다. | 토스 | 고침 — **새 `.ait` 업로드 필요** |
| 2 | 상품 검색으로 받은 링크에 채널 아이디(subId)가 빠져 있었음. 링크 자체는 추적되지만 리포트를 채널 `choiceflow` 로 거르면 보이지 않는다. | 웹·안드로이드·토스 | 고침 (배포됨) |
| 3 | 상품을 못 찾은 카드와 "관련 상품" 링크는 `/api/coupang` 을 거쳐 나간다. 1번을 처음 고칠 때 바깥 주소만 SDK 로 넘기게 해서, 이 링크들은 토스에서 여전히 열리지 않았다. | 토스 | 고침 (이번 배포) |
| 4 | `/api/coupang` 이 쿠팡 딥링크 만들기에 실패하면 추적 표시가 전혀 없는 일반 쿠팡 검색으로 조용히 보냈다. 눌러도 수수료가 0 이다. 운영 서버에서 실제로 실패하고 있었는지는 아래 점검 주소로 확인해야 한다. | 웹·안드로이드·토스 | 보강 — 딥링크가 실패하면 먼저 상품 검색의 추적 링크로 보내고, 그것도 안 될 때만 일반 검색으로 보낸다 |

### 플랫폼별 점검 결과

**웹 (choice.ymstudio.co.kr)**
- 쿠팡 링크는 새 탭으로 정상적으로 열린다.
- 2번(채널 아이디)과 4번(추적 없는 대체 링크)만 해당. 둘 다 고쳤다.
- 쿠팡 파트너스 고지 문구는 결과 화면, 공유 화면, 비교 화면, 푸터에 모두 있다.

**Google Play 앱 (안드로이드)**
- 앱은 운영 웹사이트를 그대로 띄운다(Capacitor `server.url`). 그래서 웹 쪽 수정이 앱에도 바로 들어간다. **새 AAB 를 올릴 필요는 없다.**
- 바깥 주소(쿠팡)로 가는 링크는 Capacitor 가 앱 밖(브라우저 또는 쿠팡 앱)으로 연다. 코드상으로는 정상 동작해야 한다. 다만 실제 기기로는 확인하지 못했다(아래 확인 방법 3).

**토스 미니앱**
- 1번 때문에 토스로 들어온 사람의 쿠팡 클릭은 그동안 사실상 0 이었다.
- 웹사이트가 링크 누름을 껍데기에 넘기고, 껍데기가 토스 SDK `Device.openURL` 로 연다.
- 웹사이트 쪽은 배포됐다. **껍데기(`choiceflow.ait`)는 토스 콘솔에 새로 올려야 적용된다.**
- 새 껍데기를 올리기 전에는 웹사이트가 예전처럼 동작한다(더 나빠지지 않는다).

### 새로 생긴 점검 주소

`https://choice.ymstudio.co.kr/api/coupang/check`

브라우저 주소창에 넣으면 실제 쿠팡 API 로 링크를 하나 만들어 보고, 그 링크에 추적 표시와 채널 아이디가 붙는지 한국어로 알려 준다. 열쇠 값은 보여 주지 않는다. 쿠팡 호출 한도를 아끼려고 결과를 10분 동안 그대로 쓴다.

- `"정상 — ..."` 이면 링크는 문제없다.
- `"문제"` 나 `"일부 문제"` 이면 `productSearch.note` 와 `deepLink.error` 를 보면 어디서 끊기는지 알 수 있다.

### 직접 확인해야 할 것

1. **점검 주소 열기** — 위 주소를 열고 `verdict` 줄을 확인한다.
2. **토스** — `choiceflow.ait` 를 앱인토스 콘솔에 올리고 QR 테스트 → 추천 결과에서 쿠팡 버튼을 누른다 → 쿠팡이 열리면 정상. "관련 상품" 링크도 눌러 본다.
3. **안드로이드** — 앱에서 추천 결과의 쿠팡 버튼을 누른다 → 브라우저나 쿠팡 앱이 열리면 정상. 돌아왔을 때 결과 화면이 그대로인지도 본다.
4. **쿠팡 파트너스 리포트** — 채널 필터를 "전체"로 두고 하루 이틀 뒤 클릭 수를 확인한다. 이전 링크에는 채널 아이디가 없었으므로 `choiceflow` 로 거르면 과거 클릭이 안 보인다.
5. **Vercel 로그** — `[coupang] Deep-link generation failed` 가 보이면 딥링크 권한이나 열쇠를 확인한다.

참고로 현재 방문자 수 자체가 적다(토스 일 사용자 1–5명, 한 달 약 57명). 링크가 정상이어도 결제는 한동안 드물 수 있다.

### 추천 결과 정확도 (이번 기간 수정 묶음)

- 맨 위 카드를 종합 적합도 1위로 맞춤
- 가성비 → 한 단계 위 → 검증 우선 → 가장 추천 딱지를 가격 순서와 맞춤, 화면 값과 딱지가 어긋나면 검증에서 걸러냄
- 본체 자리에 부속품·소모품(패드, 필터, 세제, 향기 시트 등)이 들어오지 않게 함
- 청소기는 무엇을 어떻게 닦는지(물걸레, 바닥 등)까지 보고 고름
- 단점 문구가 상품의 값·브랜드·쓰임새와 맞는지 확인
- 받는 사람과 쓰는 사람을 갈라 읽음(남편, 아이, 부모님 등)
- 예산을 넘는 상품은 후보에서 빼고, 후보가 모자라면 화면에 알림
- 한 브랜드가 후보를 다 차지하지 않게 하고, 아는 제조사를 하나는 둠
- 지금까지 보고된 18가지 유형을 감사 시나리오로 만들어 `npm test` 때마다 함께 돌림
